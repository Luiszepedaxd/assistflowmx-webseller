# 🚀 Guía Rápida - AssistFlowMX

## ⚡ Comandos Esenciales

### Para correr el proyecto localmente:
```bash
npm run dev
```
Se abre automáticamente en `http://localhost:3000`

### Para hacer build de producción:
```bash
npm run build
```

### Para desplegar a Vercel:
```bash
npm run deploy
```

## 📝 Flujo de Trabajo Recomendado

1. Hacer cambios en el código
2. Probar localmente: `npm run dev`
3. Hacer commit: `git add .` → `git commit -m "mensaje"` → `git push`
4. Vercel desplegará automáticamente si está conectado con GitHub

## 🆘 Solución Rápida de Problemas

**Problema**: El proyecto no corre
- Solución: `npm install` (reinstalar dependencias)

**Problema**: Cambios no se ven
- Solución: Refrescar el navegador (Ctrl+F5) o reiniciar `npm run dev`

**Problema**: Error en build
- Solución: Revisar la consola para ver el error específico
